# 🕷️ Spider Bot (Quadruped Robot)

## 📌 Overview
This project is a quadruped spider robot built using Arduino and servo motors. The robot uses a predefined gait sequence to simulate walking and turning motions. It also includes an OLED display for simple eye animations and visual feedback.

This project was developed during the early phase of my learning to understand robotics fundamentals like motion control, gait planning, and synchronization of multiple actuators.

---

## ⚙️ Key Features
- Quadruped robot with four-leg walking mechanism  
- Servo motor control using PWM signals  
- Predefined gait sequence for movement  
- Coordinated movement of multiple actuators  
- OLED display for eye animations  
- Arduino-based control system  

---

## 🛠️ Technologies Used
- Arduino  
- Embedded C  
- Servo Motors  
- OLED Display (SSD1306)  
- PWM Control  

---

## 🚀 How it Works
- Each leg is controlled using multiple servo motors  
- A predefined gait sequence controls the movement of legs  
- Arduino sends PWM signals to control servo angles  
- OLED display shows animated eyes for feedback
